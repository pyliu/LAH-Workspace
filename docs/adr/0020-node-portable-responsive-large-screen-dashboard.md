# 0020. Node 沙盒監管工具大螢幕響應式儀表板與內嵌日誌工作台架構

- 日期：2026-11-05
- 狀態：Accepted
- 決策者：pyliu, Antigravity

---

## 1. 背景與問題脈絡 (Context)

智慧控管與監控系統之可攜 Node.js 沙盒監管工具（`tools/node-portable`）在視窗預設尺寸（1000x675）下，已達成無全域滾動條與緊湊排版之目標。

然而，當操作人員將應用程式視窗拖曳放大或點擊 Windows「最大化」按鈕（通常為 1920x1080 Full-HD 解析度）時，面臨以下介面空間利用不彰的問題：
1. **單欄過度橫向延展**：分頁 1（安裝部署）將輸入框與選項卡片橫向拉伸至近 1900px，缺乏視覺焦點，且垂直方向下半部留存超過 50% 之大面積空白。
2. **日誌與狀態割裂**：分頁 2（PM2 專屬控制台）在大螢幕下表格下方留白過多，而檢視業務進程日誌時仍必須點擊按鈕彈出 Modal 遮罩視窗，無法在全螢幕寬闊視野下同時監看「受管進程清單」與「即時輸出日誌」。

為充分發揮大螢幕空間優勢，需建立自動響應之雙欄工作台與內嵌即時日誌串流架構。

---

## 2. 決策方案評估 (Options Considered)

1. **方案 A：CSS 斷點響應式大螢幕雙欄工作台與內嵌日誌串流 (Adopted)**
   - 做法：
     - 利用 CSS 媒體查詢（`@media (min-width: 1100px) and (min-height: 720px)`）感知大螢幕與最大化狀態。
     - **分頁 1（安裝部署）**：自動由單欄切換為左右雙欄工作台。左欄承載安裝路徑與執行選項；右欄內嵌安裝進度終端與沙盒資安規格解說，左右平衡。
     - **分頁 2（PM2 控制台）**：受管業務表格下方直接掛載「內嵌式即時日誌流（Inline Live Log Stream）」，點選表格進程即刻於當前畫面滾動輸出 stdout/stderr，免除彈窗阻斷，實現狀態與日誌一體化監管。
   - 優點：小視窗保持輕量緊湊，大視窗自動化身為專業監控儀表板，零手動切換成本。
   - 缺點：前端需同時維護小視窗 Modal 彈窗與大螢幕內嵌日誌的雙向資料同步。

2. **方案 B：手動切換開關**
   - 做法：於標題列提供手動「切換工作台模式」按鈕。
   - 缺點：操作繁瑣，維運人員往往忘記手動切換。

3. **方案 C：全域拉伸但維持既有元素**
   - 做法：僅將既有卡片與字體等比放大。
   - 缺點：無法提供更多實質維運機能，且版面空曠感依舊存在。

---

## 3. 決策結果 (Decision Outcome)

採納 **方案 A**。

1. **響應式斷點與架構約束**：
   - 基準斷點：`@media (min-width: 1060px) and (min-height: 600px)`。
   - 視窗預設為 1000x675 時：強制鎖定輕量檢視模式，維持現行無捲軸之緊湊排版與彈窗日誌。
   - 視窗最大化或拉大時：平滑觸發大螢幕工作台樣式。

2. **分頁 1 縱向 Flex 彈性滿版工作台與字體級距 (Studio Layout & Vertical Flex Fill)**：
   - 縱向 Flexbox 100vh 撐滿：在大螢幕模式下設定 `body { height: 100vh; overflow: hidden; display: flex; flex-direction: column; }`，消弭傳統文件流排版造成的底部 1/3 留白。
   - 上半部主工作台（雙欄平齊）：左欄（480px）承載安裝配置、環境偵測與操作按鈕，卡片垂直均勻分佈；右欄（1fr）承載即時部署日誌終端（`#inline_install_log_box`），高度隨容器 `flex: 1` 彈性撐滿（由 230px 擴展至 380px~450px，可視行數翻倍）。
   - 下半部滿版維運規格（100% 橫貫全寬）：左卡呈現沙盒資安邊界三特點，右卡呈現自動化部署流程檢核 SOP 表格，垂直平穩托住底層。
   - 大螢幕字體縮放級距：全域基準字體由 13px 適度放大至 14px，控制項與按鈕 padding 增加 2px，兼顧高解析度大螢幕易讀性與專業控制台俐落感。

3. **分頁 2 內嵌即時日誌串流 (Inline Live Log Stream)**：
   - 受管進程表格點擊選取（Active Row）：表格點選任意進程時，行高反白突顯。
   - 內嵌日誌面板：緊接於受管表格下方，提供「即時日誌預覽 (Inline Log Tail)」，內建快速分頁切換（標準輸出 out / 錯誤日誌 err）與行數選單，支援即時自動刷新。
   - 底部保留精簡版 CLI 速查與狀態自癒指引，使整個 1080p 畫面專業、緊湊、資訊密集且高機能。

---

## 4. 影響與相容性說明 (Consequences)

- **使用者體驗**：在小螢幕筆電與 1080p 大螢幕桌機之間獲得最佳視覺與操作體驗，大螢幕不再浪費任何空間。
- **維運效率**：在大螢幕維運時，點選進程直接於同畫面檢視日誌，監管流暢度大幅提升。
- **向下相容性**：既有 Tauri 2 後端 API（`get_log_tail`、`get_console_overview` 等）無須改動，純前端響應式升級，穩定無風險。
