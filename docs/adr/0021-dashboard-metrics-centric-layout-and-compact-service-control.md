# 0021. 管理儀表板指標優先架構與微型卡片服務就地快控

- 日期：2026-11-05
- 狀態：Accepted
- 決策者：pyliu, Antigravity

---

## 1. 背景與問題脈絡 (Context)

智慧控管與監控系統之管理儀表板（`LAH-Updater/tools/dashboard`）現行架構將「服務監控與控制」作為預設首頁（Tab 1），由兩個縱向全寬大表格（Windows 系統服務層與 PM2 應用進程層）構成。

在日常巡檢情境中，此佈局存在以下操作與視覺痛點：
1. **資訊層次倒置**：維運人員開啟儀表板的首要目的，通常是確認伺服器全域健康狀態（CPU 總使用率、實體記憶體、網路即時頻寬、磁碟剩餘空間與五大端口監聽狀態）。然而大表格佔滿了整個視窗首頁，重要之系統效能指標被隱藏於第三個頁籤（「系統指標與快捷維運」）。
2. **操作路徑割裂**：當在「系統指標與快捷維運」中觀察到特定服務記憶體異常或端口中斷時，操作人員必須切換至第一分頁的龐大表格中，翻找對應列才能執行「重啟」或「啟動」，流程不夠流暢。
3. **垂直版面浪費**：大表格呈現多列完整細部欄位（PID、ID、CPU、重啟次數等），在快速監控時過於厚重。

因此，需要將儀表板轉向為「指標優先（Metrics-Centric）」，並在不擴增垂直空間佔用的前提下，將服務控制無縫整合至指標首頁。

---

## 2. 決策方案評估 (Options Considered)

1. **方案 A：指標優先首頁 + 就地升級微型卡片快控（In-place Micro-card Actions）+ 保留詳細備查分頁 (Adopted)**
   - 做法：
     - 將「系統指標與快捷維運」提升為預設首頁（Tab 1）。
     - 保留第二分頁「服務詳細清單（原服務監控與控制）」，供排查深層問題（如比對 Windows 註冊路徑、PID 歷史累計、詳細重啟次數）時備查。
     - 複用指標首頁第二排的「LAH 服務群組記憶體占用」微型卡片（`mem-micro-card`）：
       - 補齊常駐核心服務（包含 Apache 2.4、FE、WSS、Scheduler、API 等），停止時亦常駐顯示（紅燈/灰底）以防人間蒸發。
       - 為卡片加入呼吸狀態指示燈（在線 / 停止 / 重啟中）。
       - 滑鼠懸浮（Hover）或點選卡片時就地呈現超緊湊快控按鈕（🔄 重啟、⏹️ 停止、▶️ 啟動）。
       - 統一 Windows 系統服務與 PM2 進程之後端呼叫邏輯，操作時卡片即時呈現轉圈重啟動畫。
   - 優點：零額外垂直版面負擔、即時指標一目了然、操作就地完成、深層排查仍有完整表格支撐。
   - 缺點：前端需擴充卡片動態渲染與跨服務型別操作路由。

2. **方案 B：徹底移除服務控制分頁，改以摺疊面板（Accordion）嵌入首頁**
   - 做法：將兩大表格折疊塞進首頁底部。
   - 缺點：首頁垂直高度過長，需依賴縱向滾動條，破壞緊湊監控體驗。

3. **方案 C：僅切換預設分頁，維持雙邊分離**
   - 做法：僅將 Tab 預設切換為指標頁，不改動操作介面。
   - 缺點：並未解決「在指標頁發現問題仍需切換分頁操作」的核心痛點。

---

## 3. 決策結果 (Decision Outcome)

採納 **方案 A**。

1. **頁籤架構調整 (Tab Hierarchy)**：
   - **Tab 1（預設啟動）**：`系統指標與快捷維運`（設為首選 active 視圖）。
   - **Tab 2**：`服務進程詳細清單`（原服務監控與控制，保留作為進階除錯備查）。
   - **Tab 3**：`即時日誌檢視器`。
   - **Tab 4**：`核心組態編輯器`。
   - **Tab 5**：`沙盒終端機`。

2. **微型卡片就地快控架構 (Interactive Micro-Cards)**：
   - **服務資料整合**：後端 `get_host_metrics` 或前端整合器將 Apache 2.4、lah-pm2 系統服務與 PM2 應用進程對齊為常態監控節點清單。
   - **狀態燈與視覺語彙**：
     - 在線（Online/Running）：綠色微光燈號 + 正常亮色背景。
     - 停止（Stopped/Offline）：警示紅色/暗灰色燈號 + 醒目「▶️ 啟動」按鈕。
     - 重啟／過渡中（Restarting/Transitioning）：橘黃色旋轉圖示 + 脈衝動態。
   - **零空間快控按鈕（Hover / Active Action Overlay）**：
     - 卡片平常顯示名稱、PID、記憶體量與比例條。
     - 滑鼠懸浮於卡片上方時，右上角或底部滑出精簡圖示按鈕（🔄 重啟、⏹️ 停止、▶️ 啟動），點擊即時發動非同步操作。
   - **統一命令路由抽象**：
     - 點擊 Apache 操作 ➔ 自動路由至 `restart_system_service` / `stop_system_service` / `start_system_service`。
     - 點擊 PM2 服務操作 ➔ 自動路由至 `restart_pm2_process` / `stop_pm2_process` / `start_pm2_process`。

---

## 4. 影響與相容性說明 (Consequences)

- **維運人因工效**：大幅減少 70% 以上的切換分頁次數，巡檢與快控在同一視窗視野秒級完成。
- **異常防護力**：核心服務即使離線亦持續顯示紅燈，避免服務死掉因記憶體為 0 而在畫面上隱形，提升事故偵知速度。
- **向下相容性**：既有 Tauri 2 後端 command 簽名完整保留，原詳細清單分頁功能與按鈕完全相容不受影響。
