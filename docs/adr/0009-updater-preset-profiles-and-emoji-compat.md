# ADR 0009: 自動更新工具維運情境快選設定檔與跨平台字元相容性策略

- **狀態 (Status)**: 已通過 (Accepted)
- **日期 (Date)**: 2026-11-02
- **決策者 (Deciders)**: 使用者 (User), Antigravity Agent

---

## 1. 背景與脈絡 (Context)

智慧控管與監控系統維運工具（`LAH-Updater`）在現場伺服器升級時，面臨維運操作流暢度與不同作業系統字型相容性之需求：

1. **特定圖示於 Windows Server 顯示異常（豆腐塊 `□`）**：
   原分類快選「🧩 核心套件 (node_modules)」所採用的拼圖圖示（`🧩`, U+1F9E9）發布於 Unicode 11.0 (2018 年)。部分 Windows Server 2016 與未更新之環境內建 `Segoe UI Emoji` 缺少該字形，導致圖示呈現方框豆腐塊，影響畫面專業度。
2. **快選分類與實際維運情境存在落差**：
   舊有快選僅提供純粹的目錄分類（`基礎環境 (base)`、`程式修補 (patch)`、`核心套件 (node_modules)`），維運人員在進行標準的「原機原地升級（AppServ 導入 PHP 8.5、VC++、Node 與 LAH-API）」或「全新伺服器全量佈署」時，仍須逐項手動切換基礎環境、應用模組與系統服務配置，繁瑣且容易遺漏關鍵項目。
3. **基礎環境 (base) 快選使用率低且易生誤導**：
   基礎環境包包含互斥或不同世代之套件（如 Apache、PHP7、PHP85、Node），維運同仁甚少進行「僅安裝基礎環境而不安裝任何應用程式」之操作，該快選按鈕實用價值低，應予精簡以釋出按鈕空間。

---

## 2. 決策與實作 (Decisions & Implementation)

### 決策一：豆腐塊圖示替換為高相容經典圖示
- 將「核心套件 (node_modules)」之按鈕圖示全面由 Unicode 11.0 `🧩` 替換為 Unicode 6.0 經典圖示 `📚` (Books, U+1F4DA)。
- 支援度覆蓋 Windows Server 2012 / 2016 / 2019 / 2022，保證 100% 正常渲染無缺字豆腐塊。

### 決策二：新增「🔄 原地升級」情境快選
- 精準連動原機原地升級 4 大關鍵套件：
  - `php85` (PHP 8.5 執行環境)
  - `vcredist` (VC++ 執行期間相依套件)
  - `node` (Node.js 綠色執行環境)
  - `lah_api` (後端 PHP8 更新包)
  - （其餘 Apache、PHP7、前端、即時通訊套件自動取消勾選，保留現有機台既有核心）
- 同步一鍵套用原機升級標準服務配置：
  - 自動註冊 Web 服務：`true`
  - 自動註冊 PM2 服務：`true`
  - 套用資安弱點強化：`true`
  - 更新後重啟 Web 服務：`true`
  - 更新後重啟 PM2 服務：`false`
  - 從備份還原自訂配置：`false`

### 決策三：新增「🌟 全新安裝」情境快選
- 一鍵全選所有已就緒（`exists === true`）之更新包（基礎環境 + 應用模組全選）。
- 同步套用全新安裝標準服務配置全開（包含重啟 PM2 服務：`true`）。

### 決策四：移除「🏛️ 基礎環境 (base)」快選並精簡工具列
- 移除「基礎環境 (base)」按鈕，工具列改為「情境快選」與「分類快選」雙分組結構：
  - 情境快選：`[🌟 全新安裝]` `[🔄 原地升級]` `[⬜ 全部取消]`
  - 分類快選：`[📦 程式修補 (patch)]` `[📚 核心套件 (node_modules)]`
- 排版與下方雙欄視覺完美切齊。

---

## 3. 效益與影響 (Consequences)

1. **消弭跨平台亂碼**：全面消除舊版 Windows Server 豆腐塊，確保所有文字圖示呈現 100% 完整清晰。
2. **極致維運效率**：原機升級與全新安裝一鍵即可完成整套更新包與系統服務選項之標準配置，完全杜絕人為勾選錯誤。
3. **版面緊湊專業**：移除低頻冗餘按鈕，工具列排版更加緊湊平衡。
