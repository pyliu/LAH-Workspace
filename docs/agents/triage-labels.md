# Triage 標籤 (Triage Labels)

各項技能預設使用五種標準的 Triage 角色。此檔案將這些角色對應至本專案 Issue 追蹤器中所使用的實際標籤字串。

| mattpocock/skills 預設標籤 | 本專案追蹤器使用標籤 | 說明與意涵                               |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 維護者需要評估此 Issue                   |
| `needs-info`               | `needs-info`         | 等待回報者提供更多詳細資訊               |
| `ready-for-agent`          | `ready-for-agent`    | 規格已明確完整，可由 Agent 自主接手實作  |
| `ready-for-human`          | `ready-for-human`    | 需由工程師手動實作處理                   |
| `wontfix`                  | `wontfix`            | 經評估後決定不予處理                     |

當 Skill 提及某個角色時（例如「套用 AFK-ready triage 標籤」），請使用此表對應的標籤字串。

若未來專案慣用標籤有所調整，可直接修改「本專案追蹤器使用標籤」欄位。
