LAH-Workspace 地政整合智慧管控系統 — 全域架構與 Git 實作手冊

本工作區採用「根目錄容器 + 五大 NTFS Junction 獨立子專案」之 Multi-repo 架構，串聯地政業務 REST API、智慧監控前端、高併發 WebSocket 即時通訊伺服器、Tauri v2 跨平台桌面客戶端與原生自動部署套件，並內建完整的 AGENTS.md 形式化架構契約與 54 個台灣繁體中文工程技能（pstack）。

圖 2：根目錄與五大獨立 Git Junction 容器版控結構圖 Multi-Repo Architecture

工作區根目錄（d:\DEV\lah-workspace）本身是一個輕量級 Git 儲存庫，透過 .gitignore 明確排除五個子專案目錄，並以 Windows NTFS Junction（Mode: l----）掛載五個平級獨立 Git 儲存庫。執行任何 Git 指令前，務必確認目前工作目錄位於正確的儲存庫。

左圖展示 LAH-API 如何透過 Apache 2.4 分流 PHP 7.3 生產軌道與 PHP 8.5 FastCGI 現代化軌道並共享單一真實資料源；右圖展示 lah-messenger 如何透過 electron-shim.js 讓既有 Vue 2 元件零修改無縫運行於 Rust Tauri v2 核心之上。

圖 4：LAH-Updater 原始碼打包與目標伺服器 5 階段自動更新流水線 Deployment Pipeline SVG

LAH-Updater 由一個零外部依賴的 Python 打包腳本（pack/pack.py）與三個 Rust + Tauri 2 靜態編譯原生工具（updater、backuper、uninstaller，執行檔體積僅 9~12 MB，冷啟動 <0.3 秒）組成，負責將開發工作區產物安全部署至各地政事務所伺服器。

圖 5：本機開發啟停腳本與跨庫同步作業流程圖 Operational Workflow SVG

根目錄提供三支自動化批次腳本，具備通訊埠佔用偵測與 PM2 / Apache24 系統服務保護機制，避免誤殺正式常駐服務。

一鍵同步所有 Git 專案
.\git-pull.bat

自動拉取根目錄與 5 個子專案最新遠端分支。

一鍵啟動本機開發環境
.\start_dev.bat

自動偵測 Port 80 / 8085 / 8080 / 8081 並開啟瀏覽器。

一鍵釋放臨時開發行程
.\stop_dev.bat

安全關閉臨時開發程序，保留 Apache 與 PM2 常駐服務。
