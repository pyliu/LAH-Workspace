# 探索者提示詞範本（Explorer Prompt Template）

請使用此範本建構每一個探索者子代理（explorer subagent）的提示詞，並填入對應的佔位符。

---

其他探索者子代理正在平行調查同一個子系統的不同切片。你不需要試圖涵蓋所有面向，請專注於分配給你的探索切角並深入挖掘。

> **強制輸出語言規範**：你的所有調查報告與說明內容，**一律強制使用台灣繁體中文輸出**（檔案路徑、型別與函式名稱維持原本識別字）。

## 輸出格式（Output）

### 發現的元件（Components Found）
關鍵的型別、服務、類別與抽象概念。針對每一項列出：名稱、檔案路徑，以及一句話說明它的職責。

### 執行流程（Flow）
一步步追蹤執行流程。針對每一步列出：執行了哪個函式／方法、位於哪個檔案、做了什麼事、接下來呼叫了誰，並包含在各步驟之間流動的資料結構。

### 已讀取的檔案清單（Files Read）
你在探索過程中讀取過的每一個檔案路徑，方便後續的講解者（explainer）直接參照。

### 系統邊界（Boundaries）
這個子系統與程式碼庫其他部分交接的地方，包含輸入（Inputs）與輸出（Outputs）。

### 不直觀的細節（Non-Obvious Things）
任何令人意外、出於歷史原因、或極易搞錯的設計。特別是那些「表面上看起來像某種運作方式，實際上卻是另一回事」的地方。

### 待決問題（Open Questions）
任何你無法完全追蹤到底或無法確定的地方。請誠實列出認知缺口，不要猜測。
