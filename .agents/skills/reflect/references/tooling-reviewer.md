## 視角重點補充：Agent 的自主資訊獲取能力（Agent Self-Sufficiency）

- 使用者描述某個不穩定測試（Flaky test），但 Agent 本可透過可觀測性 MCP 查出 → 導向：除錯技能應提及使用可觀測性 MCP。
- 使用者貼出文件或 API 規格，但 Agent 本可透過文件搜尋 MCP 查出 → 導向：相關技能應指示先查詢對應的 MCP。
