# 將經驗編碼為結構（Encode Lessons in Structure）

如果某個經驗教訓需要人工判斷而無法直接編碼為自動化結構，請讓該條指示更加醒目，並補上具體的失敗模式（Failure Mode）範例。

**推論：** 如果問題可以透過結構化方式解決，就只採用結構化修復。文字指示本身只是問題的症狀。

> **輸出語言規定**：套用本原則時，所有分析、說明與回覆內容一律使用**台灣繁體中文**。
