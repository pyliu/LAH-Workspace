# GLOSSARY.md 格式規範

## 結構範例

```markdown
# 系統領域詞彙表 (Context Name)

簡述本系統或 Context 的主要業務範圍與職責。

## 核心術語 (Language)

**案件 (Case)**:
地政登記或測量之單一收件案號主體。
_避免使用_: 工單, 任務, 交易

**推播頻道 (Channel)**:
即時通訊中特定事務所或群組之獨立廣播頻道。
_避免使用_: 聊天室, 房間

**操作員 (Operator)**:
擁有系統管控與跨所檢視權限的內部地政人員。
_避免使用_: 使用者, 客戶
```

## 撰寫原則

- **具備主見 (Be opinionated)**：同一個概念若有多種稱呼，選定最佳標準詞，並將其他詞列於 `_避免使用_`。
- **定義緊湊精確**：最多 1 至 2 句話，定義它「是什麼」，而非「如何做」。
- **僅收錄本專案專屬領域術語**：通用程式技術術語（如 timeout、ORM、Promise）不屬於業務領域辭典。
- **自然分組**：若領域較龐大，可使用二級標題分類。
