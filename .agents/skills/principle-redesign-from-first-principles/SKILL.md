# 從第一性原理重新設計（Redesign From First Principles）

在整合新變更時，不要將它像補丁一樣硬釘（Bolt on）在既有設計上。請以「假設這項需求從一開始就是系統的核心基礎假設」為前提，進行重新設計。

- 閱讀所有受影響的檔案，徹底理解目前的設計架構
- 問自己：「如果我們帶著這項新需求從頭撰寫這個模組，我們會打造出什麼樣的結構？」
- 將這項變更完整貫穿到每一個關聯處：型別定義、文件、範例以及設計理念（Rationale）章節
- 先通盤思考完整的重新設計，再以增量方式逐步交付

這是將新變更整合進既有設計時，用來保護系統未來選擇權（Option Value）的核心方法。
