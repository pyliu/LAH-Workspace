# 帶文件產出的深度盤問 (Grill with Docs)

本技能結合了 **`grilling`**（深度提問）與 **`domain-modeling`**（領域建模）。

---

## 執行流程

1. **啟動深度提問（Grilling）**：
   - 建立待決策事項之決策樹。
   - 分輪次提出前沿問題，為每題提供具體明確的推薦選項。
   - 讓使用者能以最少的心智負擔做出關鍵裁決。

2. **同步淬鍊領域辭典與架構決策（Domain Modeling）**：
   - 當對話中出現關鍵業務術語或修正模糊詞彙時，立即於專案中維護 `GLOSSARY.md`。
   - 當觸發高成本、具深遠影響且有明確取捨的重大決策時，於 `docs/adr/` 產出對應的架構決策紀錄。

3. **產出結論**：
   - 當決策樹所有分支前沿皆已收斂且無隱含假設時，整理決策與領域文件摘要，供後續轉為規格（`/to-spec`）或任務票券（`/to-tickets`）。
