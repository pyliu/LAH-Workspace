# 任務交接緊湊器 (Handoff)

當對話即將達到 Context 上限、切換工作階段，或需要將任務移交給下一個 Agent 時使用。  
將對話脈絡濃縮為結構化的交接摘要。

---

## 執行要點

1. **不重複既有文件**：  
   若工作成果已保存在規格書、ADR、Git Commit 或 Diff 中，僅需引述檔案路徑，切勿冗長重複貼上。
2. **遮蔽敏感資訊**：  
   嚴禁在交接文件中記錄 API 金鑰、密碼或個資。
3. **儲存位置**：  
   交接文件可輸出於使用者的作業系統暫存目錄（Windows `%TEMP%`）或本專案之 `.scratch/handoffs/`。

---

## 交接文件範本

```markdown
# 任務交接文件 (Handoff Summary)

**交接時間**: [日期時間]  
**前一階段目標**: [簡述先前完成的任務]  

## 1. 目前狀態與完成項目
- 已確認之規格：[路徑]
- 已完成之檔案變更：[檔案清單]
- 驗證狀態：[通過之測試與檢查]

## 2. 下一階段目標與待辦項目
- 待處理之核心任務：
- 待解開之前置依賴：

## 3. 建議調用技能 (Suggested Skills)
- [技能名稱 1]: 用於 ...
- [技能名稱 2]: 用於 ...

## 4. 關鍵注意事項與潛在地雷
- 跨專案介面相容性提醒或資料庫注意事項。
```
